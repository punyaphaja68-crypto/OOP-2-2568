
วิธีการติดตั้งและรันเกมด้วย uv
1. เริ่มต้นสร้างสภาพแวดล้อม (ครั้งแรกที่ทำโปรเจกต์)
    เปิด Terminal (PowerShell) ในโฟลเดอร์ D:\Work\Rocket\OOP-2-2568 แล้วพิมพ์:
    # สร้างไฟล์โปรเจกต์เบื้องต้น
uv init
# สร้าง Virtual Environment และกำหนดเวอร์ชัน Python
uv venv

2. ติดตั้ง Library ที่ต้องใช้
    เกมของมิเกลใช้ pygame เป็นหลัก ให้สั่งติดตั้งผ่าน uv ได้เลย (มันจะลงให้ในโฟลเดอร์ .venv ของโปรเจกต์นี้เท่านั้น ไม่ไปรกเครื่อง):
uv add pygame

3. วิธีการรันเกม (ทำทุกครั้งที่จะเล่น/ทดสอบ)
    ไม่ต้องพิมพ์ python main.py แบบเดิมแล้ว ให้ใช้คำสั่งของ uv แทนเพื่อให้มันดึง Library จากตัวที่เราเพิ่งลงไปมาใช้:
uv run main.py
